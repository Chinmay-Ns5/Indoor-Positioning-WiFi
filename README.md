# Indoor Positioning Using WiFi Fingerprints

## Project Overview

This project investigates indoor positioning using WiFi RSSI fingerprints from the UJIndoorLoc dataset.

The project compares multiple machine learning approaches for floor prediction, including:

- PCA
- k-Nearest Neighbors (kNN)
- Support Vector Machine (SVM)
- Decision Tree
- Gradient Boosting

The project also investigates model combinations, robustness to missing WiFi signals, and final validation on unseen data.
